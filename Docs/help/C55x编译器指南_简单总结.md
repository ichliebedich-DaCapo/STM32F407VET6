以下是关于TMS320C55x C/C++编译器的使用指南，结合您已有的GCC经验进行对比说明，帮助您快速上手：

---

### 一、编译流程对比
#### 1. **基本编译命令**
- **GCC**：`gcc -O2 -o output input.c`
- **C55x**：使用`cl55`命令，基础编译链接一步完成：
  ```bash
  cl55 -O3 --opt_level=3 -z --rom_model input.c -o output.out -lrts55.lib
  ```
    - `-O3`：最高优化级别（类似GCC的`-O3`）
    - `--rom_model`：指定运行时初始化方式（ROM自动初始化）
    - `-lrts55.lib`：链接运行时库（类似GCC的`-lc`）

#### 2. **分步编译**
- **GCC**：预处理→编译→汇编→链接
- **C55x**：
  ```bash
  cl55 -c -O2 input.c          # 生成input.obj
  cl55 -z --rom_model input.obj -o output.out  # 链接
  ```

---

### 二、关键编译选项
#### 1. **优化选项**
- **优化级别**：
    - `--opt_level=0`（无优化）到`--opt_level=3`（激进优化）
    - 类似GCC的`-O0`到`-O3`，但C55x优化更针对DSP硬件特性（如硬件循环、并行指令）。
- **循环展开**：
  ```c
  #pragma UNROLL(4)  // 提示编译器展开循环4次
  for (int i=0; i<100; i++) {...}
  ```
- **函数内联**：
  ```c
  #pragma FUNC_ALWAYS_INLINE(func)  // 强制内联函数
  ```

#### 2. **内存模型**
- **小内存模型（默认）**：数据指针16位，适用于片上RAM。
- **大内存模型**：`--memory_model=large`，数据指针23位，支持扩展内存。
    - 类似GCC的`-mcmodel=large`，但需注意硬件支持。

#### 3. **调试与诊断**
- **生成调试信息**：`--symdebug:dwarf`（类似GCC的`-g`）
- **禁用优化调试**：`--opt_level=0`避免优化干扰变量查看。

---

### 三、混合编程（C与汇编）
#### 1. **内联汇编**
- **GCC**：`asm("指令")`
- **C55x**：
  ```c
  asm(" MOV #0, AC0 ");  // 直接嵌入汇编
  ```
    - 注意：避免在优化代码中破坏C环境（如寄存器使用）。

#### 2. **调用汇编函数**
- **C声明**：
  ```c
  extern void asm_func(int arg);  // C调用汇编函数
  ```
- **汇编编写**：
  ```asm
  .global _asm_func
  _asm_func:  ; 函数名加前缀_
    ADD #1, T0  ; 参数通过T0传递
    RET
  ```

---

### 四、关键编程实践
#### 1. **中断处理**
- 使用`interrupt`关键字定义中断服务程序：
  ```c
  interrupt void ISR() {
    // 确保函数无参数、无返回值
  }
  ```
    - 需保存/恢复上下文（编译器自动处理部分寄存器）。

#### 2. **IO与硬件访问**
- 使用`ioport`关键字访问外设寄存器：
  ```c
  ioport unsigned int *port = 0x1000;
  *port = 0xFF;  // 直接操作硬件地址
  ```

#### 3. **易变变量**
- 使用`volatile`防止编译器优化：
  ```c
  volatile int *status_reg = (volatile int *)0x2000;
  ```

---

### 五、链接与内存配置
#### 1. **链接脚本（.cmd文件）**
- 定义内存布局（类似GCC的链接脚本）：
  ```text
  MEMORY {
    RAM (RWX) : origin = 0x100, length = 0x1F00
    ROM (RIX) : origin = 0x2000, length = 0x8000
  }
  SECTIONS {
    .text > ROM
    .bss  > RAM
  }
  ```

#### 2. **运行时库**
- 必须链接`rts55.lib`（小内存）或`rts55x.lib`（大内存）。
- 自定义库构建：使用`mklib`工具（文档7.4节）。

---

### 六、常见问题
1. **变量未初始化**：C55x不会自动初始化全局变量为0，需在链接脚本中配置`.bss`段填充。
2. **栈溢出**：通过`--stack_size`调整栈大小，使用`--entry_hook`添加栈检查。
3. **混合C54x代码**：使用`#pragma C54X_CALL`兼容旧版汇编。

---

通过以上对比和关键点，您可以快速将GCC经验迁移到C55x平台，充分利用其DSP优化特性。建议结合文档中的优化章节（第3章）和运行时环境（第6章）深入理解硬件特性。
